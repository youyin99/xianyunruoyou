## 二、说明文档

### 第一级任务说明

#### 1. 任务要求

第一级任务要求使用组委会下发的太平洋战区美军军事基地数据，完成GIS应用，并为每个基地建立详细说明。在此基础上，构建西太平洋战区目标特性本体，使基地从地图点位变为可计算实体。

本体采用五元组形式 TO = {E, A, R, F, Ax}：E为实体集（基地、跑道、机库、油库、雷达站、防御阵地等），A为属性集（几何、容量、状态等，区分实测值与推断值），R为关系集（从属、支撑、连通、保障等），F为行为函数（外部条件驱动的状态演化），Ax为公理集（完整性约束）。

属性按可观测性和演化性分为四类：可观测特性（OSINT直接可采，须附溯源）、功能特性（由观测推断，附规则与置信度）、状态特性（由行为函数驱动）、脆弱性特性（为第二级提供输入）。

每个断言附带置信度，数据源经D-S证据理论合成输出信任区间。溯源采用PROV-O标准。第一级还需给出失效边界，回答三个必答问题。


#### 2. 前期准备

**软件下载与安装**

Protégé Desktop：本体建模工具，完整支持OWL 2，可与HermiT推理机直接连接。从 https://protege.stanford.edu/software.php 下载，运行前需安装JDK或JRE运行环境。

HermiT推理机：用于一致性检查和子包含推理。Protégé 4.3及以上版本已预装HermiT；如未预装，将 org.semanticweb.HermiT.jar 复制到Protégé的plugin文件夹，重启后在Reasoner菜单中即可选择。

Apache Jena Fuseki：SPARQL服务器。从Apache Jena官网下载二进制发行版，解压后运行 fuseki-server 命令启动。浏览器访问 http://localhost:3030 即可使用SPARQL查询界面。

pySHACL：SHACL校验工具，纯Python模块。使用 pip3 install pyshacl 安装。命令行用法：pyshacl -s shapesGraph.ttl -m -i rdfs -a -j -f human dataGraph.ttl。

PostgreSQL + PostGIS：空间数据库。Windows用户从PostgreSQL官网下载安装包，安装时勾选PostGIS扩展；Ubuntu用户执行 sudo apt install postgresql postgis。安装后在数据库中执行 CREATE EXTENSION postgis; 启用空间功能。

QGIS：桌面GIS。从 https://download.qgis.org/ 下载安装。

CesiumJS或MapLibre：WebGIS前端。CesiumJS从 https://cesium.com/downloads/ 获取，MapLibre从 https://maplibre.org/ 获取。

**环境配置要点**

- JDK/JRE：Protégé和Jena Fuseki均依赖Java环境，建议安装JDK 11或以上版本。
- Python环境：pySHACL依赖Python 3.8+。仓库根目录提供 `environment.yml`（Python 3.11，含 rdflib、pyshacl、prov、pandas、geopandas、pyproj、psycopg2、ipykernel；channels 已配置清华镜像，海外网络可换回 conda-forge）。创建并激活：`conda env create -f environment.yml` → `conda activate xianyunruoyou`。
- Git：本体文件随代码入库，需配置Git仓库。
- PostGIS空间扩展：安装PostgreSQL后需在目标数据库中执行 CREATE EXTENSION postgis; 才能使用空间函数。


#### 3. 任务内容

**数据层**：接收组委会下发的基地数据，使用QGIS完成清洗、坐标转换和格式统一，导入PostGIS建立空间索引。按军种、类型、位置、设施等维度分层组织数据。

**GIS可视化**：在CesiumJS或MapLibre中搭建WebGIS前端，分层标绘基地数据，实现按军种筛选、点击查看详情、空间查询等功能。

**本体建模**：在Protégé中建立OWL 2本体，定义类层次、对象属性、数据属性和公理集。本体采用五元组框架，属性按四类组织，区分实测值与推断值。

**本体实例化**：基于清洗后的基地数据，在Protégé中完成实例化（ABox），将每个基地、跑道、机库等对象填充为具体个体。

**置信度与溯源**：为每个断言标注置信度，采用D-S证据理论合成输出信任区间。使用PROV-O标准记录每条数据的来源、加工过程与责任者。没有溯源的数据不进入推理。

**推理与查询**：在Jena Fuseki中加载本体和实例，通过SPARQL端点提供查询服务。实现行为函数F的状态迁移规则。

**校验与验证**：编写SHACL形状文件，对本体实例进行约束校验。运行pySHACL生成校验报告，包括缺失值、越界值和孤立实体。设计随机参数复现测试，验证状态输出与声明规则的一致性。

**失效边界分析**：回答三个必答问题，给出判定失效的最小条件集。

**基地说明**：为每个基地建立详细说明文档，涵盖地理位置、功能定位、设施构成和作战意义。借助公开智能体服务检索公开资料，经人工校对后整理。

#### 6. 常见问题

**Protégé启动报错**：检查是否已安装JDK/JRE，建议JDK 11及以上。

**Jena Fuseki无法启动**：检查Java版本和端口占用情况，默认端口3030。

**pySHACL安装失败**：确认Python版本为3.8+，建议使用虚拟环境。

**PostGIS扩展无法创建**：确认已安装PostGIS扩展包，再在目标数据库中执行 CREATE EXTENSION postgis;。

**QGIS连接PostGIS失败**：检查数据库服务是否启动，连接参数（主机、端口、用户名、密码）是否正确。
